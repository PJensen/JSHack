# Void Hole Power Pass

## Summary
Make Void Hole feel like a real gravity-well spell, not a small pulsing dark tile. Implement all three notes in a controlled v1: stronger eased void lighting, mass-aware pulling, heavier tick injury, and a final collapse burst that uses existing gore/death systems.

## Key Changes
- **Lighting intensity curve**
  - Extract the existing `computeEnvelopeValue` math into shared code, keep `blind.js` re-exporting it so current tests/API stay intact.
  - Extend `VoidHoleCast` with `holeId`, `pulseIndex`, `durationTurns`, `strength`, and `collapsing`.
  - Use an envelope over the 4-turn lifespan: turn 1 ease-in, turns 2-3 peak, turn 4 collapse/ease-out.
  - Crank display tuning: peak `voidStrength` about `2.25`, display radius about `radius * 1.8`, softer edge, darker center, stronger shake on collapse.

- **Rules behavior**
  - Add `ageTurns`/`durationTurns` to `VoidHole` so the system can compute pulse strength deterministically.
  - Increase tick damage from `4` to `7` base shadow damage per pulse.
  - Add distance scaling: center tile/adjacent targets take a bonus, outer-ring targets take base damage.
  - Keep canonical `dealDamage` so crits, resistances, death, gore, messages, and threat stay on existing paths.

- **Mass-aware pull**
  - Use `Physiology.massKg` as the pull resistance source.
  - Pull strength scales with pulse strength:
    - `<= 30kg`: up to 2 tiles on peak pulses.
    - `31-120kg`: 1 tile on normal/peak pulses.
    - `121-300kg`: 1 tile only on peak pulses.
    - `> 300kg`: no forced movement, but still damaged.
  - Existing blockers and occupancy remain respected.

- **Final collapse**
  - On the final pulse, apply a collapse burst: extra shadow damage to targets within radius 1.
  - Add a display-only collapse visual off `VoidHoleCast.collapsing`: stronger inward particles, black flash, and boosted gore impulse for deaths caused by the collapse.
  - Do not invent a second death pipeline; deaths still come from `dealDamage`.
