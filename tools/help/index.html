Query String Save Game Deaths & Tombstones

Query String Arguments

Append these parameters to the game URL to control startup behaviour.

Example: index.html?floor=5&quality=low&deity=atheism

Game Start

ParameterTypeDefaultDescription
floorint ≥ 00 Start at this dungeon depth. 0 = surface.
deitystringmolkhar Starting deity ID. Determines worship on a new game.
givestring— Give items to the player on game start. Comma-separated list of item_id or item_id*count specs. Count defaults to 1. Unknown IDs and malformed specs are skipped with a console warning.

Example: ?give=sword_plain,potion_stoneskin*3,ring_arcana
dungeonScalefloat > 0— Override the dungeon render scale factor.

Performance

ParameterTypeDefaultPersisted to localStorageDescription
quality"high" | "low"high jshack.quality low: no glow, 512 particle cap, DPR cap 1. high: full effects, 4096 particles, DPR cap 3.
dprCapfloat > 01.5 jshack.dprCap Device pixel ratio cap. Overridden by quality preset when quality is "high" or "low".
cameraLerpnumber0 No Camera smoothing factor. 0 = instant snap to player.
rulesProfile0 | 10 jshack.rulesProfile Enable ECS rules-system profiling output to the browser console.

Death Share URL (incoming params)

When a player shares their death via X/Twitter the link encodes these read-only parameters. They do not start a regular game session.

ParameterDescription
dDungeon depth where death occurred.
sScore at time of death.
seedWorld seed as a hex string (e.g. 1A2B3C).
kKiller entity name (optional).
cCause string — combat, starvation, trap, etc. (optional).

Save Game Details

localStorage key
jshack:savegame:v1
Saved when
Player rests at a bed — bed:rested event
Cleared when
Player dies — died event
